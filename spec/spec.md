## 1. 目标

把本机一个目录里的照片，通过**一条本地命令**加工成纯静态网站并发布到 AWS，供任何人通过 **S3 静态网站端点**直接访问。定位是**公开展示的个人照片珍藏库**：重整理、检索与沉浸浏览，不做云相册服务。

**成功标准**

- 几百张照片（<2GB）在数分钟内完成构建并上线。
- 线上产物不含任何拍摄位置、设备标识、原始文件名。
- 无服务器、无数据库、无 CDN、无 TLS 证书、无自有域名；可长期低维护运行。

## 2. 角色与用户故事

**主人（你）**

- US-01 一次性导入：把照片放进源目录，跑一条命令，自动完成去重校验、拍摄时间读取、多档缩略图生成、脱敏、静态站构建、上传。
- US-02 自动归档：按 EXIF 拍摄时间归入年月；按目录划分相册；支持打标签。
- US-03 增量更新：新增照片只需放进目录再跑一次命令，已有照片不被重复处理。
- US-04 结果可预期：构建结束输出报告（新增 / 跳过 / 失败数量、缺失 EXIF 的照片清单）。

**访客（任何人、无需登录）**

- US-05 时间轴浏览：按年月分组的浅色杂志式网格，滚动懒加载。
- US-06 相册视图：在「时间轴 / 相册」之间切换。
- US-07 搜索筛选：按关键词、标签、拍摄年月即时过滤。
- US-08 沉浸查看：全屏灯箱，←/→ 翻页、空格自动播放、ESC 退出。
- US-09 跨设备：手机 / 平板 / 桌面正常浏览。

## 3. 功能需求

### FR-01 输入与格式

- 源目录默认为工作区下 `photos/`；支持 JPEG / PNG / HEIC / WebP，HEIC 自动转换为 Web 格式。
- 一级子目录 = 一个相册（相册名取目录名）；根目录照片归入「未分类」。
- 无 EXIF 拍摄时间的照片用文件修改时间兜底，并写入构建报告。
- 内容相同的照片按内容哈希去重。

### FR-02 隐私与脱敏（硬性要求，不可协商）

- 产物中**不上传原始文件**，只上传重新编码后的展示尺寸图与缩略图（展示图最长边默认 2048px）。重编码即剥离 EXIF，从源头杜绝泄露。
- 移除：GPS 坐标、机身 / 镜头序列号、软件信息、原始文件名、本地绝对路径。
- 保留用于功能的：拍摄时间（年月）、宽高比、相册、标签、可选标题 / 说明。
- 界面不展示 EXIF 参数面板（第二轮未勾选）；访客不可下载原图（第二轮未勾选）。
- **站点完全公开且桶可公开读取，因此本条是唯一的隐私防线，不可降级。**

### FR-03 时间轴与相册

- 首页默认时间轴，按年 → 月分组，每组显示数量与代表图。
- 相册视图按目录分组，可进入单个相册。
- 网格在图片加载前按宽高比占位，避免布局跳动。

### FR-04 搜索与筛选

- 前端本地检索（数据与静态清单一起下发），无需后端。
- 支持关键词（标题 / 说明 / 标签）、标签、拍摄年月三类条件，可组合、实时出结果。
- 无结果时给出明确空状态与「清除筛选」入口。

### FR-05 灯箱 / 幻灯片

- 点击图片进入全屏；←/→ 或屏幕按钮翻页，空格切换自动播放，ESC 退出，移动端支持滑动。
- 预加载相邻图片；自动播放间隔默认 4 秒。

### FR-06 视觉

- **浅色杂志风**：暖白 / 浅灰底、大量留白、衬线体标题、规整网格、克制的分割线与细字重说明文字。
- 照片是主角：不加边框、不加滤镜、不做圆角堆叠。
- 基础可访问性：图片 alt 文本、键盘可达、焦点可见、文字对比度达标。

### FR-07 部署（v0.4 重写）

- 产物为纯静态文件，托管于 `ap-southeast-1`（新加坡）的 **S3 静态网站**，通过 **AWS 提供的网站端点**直接以 HTTP 访问：`http://chenyouyi.s3-website-ap-southeast-1.amazonaws.com`。
- **不使用自有域名 `chenyouyi.top`、不使用 CloudFront、不使用 ACM / TLS 证书、不提供 HTTPS**（本轮确认）。
- 桶名沿用 `chenyouyi`。因不再使用自定义域名，**桶名不再需要与域名一致**，仅为沿用以减少改动；桶名仍须合法且全局唯一。
- 桶需开启公开读取以下发静态文件（关闭 Block Public Access + 允许 `s3:GetObject` 的桶策略），但**禁止 `s3:ListBucket`**，避免对象被枚举。
- **不需要任何 DNS 记录、不需要域名备案。**
- 一条命令完成：构建 → 上传 → 输出访问地址。

### FR-08 更新

- 增量友好：新增照片放进目录后重跑同一条命令即可，未变化文件跳过上传。
- 无 CDN 缓存层，**不需要缓存刷新**；新照片上传后即时可见。产物文件名带内容哈希，保证清单更新后访客不会读到旧资源。

## 11. 架构核查与已知限制（v0.4）

### 11.1 冲突核查与结论

| 曾提出 | 核查结果 |
| --- | --- |
| ACM 证书在 `ap-southeast-1` 申请并直接绑到 S3 | ❌ 不可行：ACM 私钥由 ACM 保管，证书只能附加到 CloudFront / ALB / API Gateway 等集成服务，S3 不在其列 |
| 不用 CloudFront，S3 直接提供 HTTPS | ❌ 不可行：S3 静态网站端点只支持 HTTP |
| CloudFront 用的证书放在新加坡 | ❌ 不可行：用于 CloudFront 的 ACM 证书必须在 `us-east-1` |
| **放弃 HTTPS，改用 HTTP** | ✅ 可行：S3 静态网站 + 自有域名 CNAME（v0.3） |
| **自有域名备案未获批，改用 S3 网站端点** | ✅ **可行且更简单**：域名不再参与，DNS / CNAME / 备案 / Host 头路由约束一并消失 |

结论：接受 HTTP 且不使用自有域名后，架构为最简的纯 S3 静态托管，访问 AWS 提供的 website endpoint。

### 11.2 纯 S3 静态网站的硬性约束（v0.4 更新）

- **不再使用自定义域名**：访问走 AWS 提供的 website endpoint，因此**没有 Host 头路由约束**，桶名不必与任何域名一致，也无需任何 DNS 记录。
- **桶名**：沿用 `chenyouyi`，需合法（3~63 字符、小写字母 / 数字 / 点 / 连字符）且全局唯一；若被占用可自由改名。
- **桶必须公开可读**：静态网站托管要求对象可匿名读取；桶策略只放开 `s3:GetObject`，禁止 `s3:ListBucket`。
- **website endpoint 仅 HTTP**：`http://chenyouyi.s3-website-ap-southeast-1.amazonaws.com`（`ap-southeast-1` 为连字符格式，见 plan §6）；所有资源必须用相对路径，避免混合内容拦截。

### 11.3 已知限制（已接受）

- 浏览器地址栏会标记「不安全」；开启 HTTPS-First / 自动升级 HTTPS 的浏览器可能直接尝试 `https://` 而失败。
- 无 CDN：访客直连新加坡 S3，跨运营商 / 跨境访问速度与稳定性不确定，首屏 <2s 不保证。
- **S3 网站端点 URL 较长、不便记忆与分享**（不再有自定义域名）。
- 任何人知道桶名即可通过该端点直接访问内容（站点本就完全公开，影响有限）。
- S3 直接出站流量单价高于经 CDN 分发；访问量很小可忽略，若日后流量增大成本可能反而更高。
- 部分社交平台 / 即时通讯工具对 HTTP 链接会提示风险，分享体验受影响。
- 若日后要恢复 HTTPS 或绑定自定义域名，必须重新引入 CloudFront / Amplify Hosting 并完成域名侧流程，需重开 spec。

### 11.4 官方依据

- [Amazon S3 网站端点](https://docs.aws.amazon.com/AmazonS3/latest/userguide/WebsiteEndpoints.html)：网站端点不支持 HTTPS。
- [AWS General Reference · S3 endpoints](https://docs.aws.amazon.com/general/latest/gr/s3.html)：`ap-southeast-1` 的 website endpoint 为 `s3-website-ap-southeast-1.amazonaws.com`，协议 HTTP。
- [CloudFront SSL/TLS 证书要求](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/cnames-and-https-requirements.html)：用于 CloudFront 的 ACM 证书必须在 `us-east-1`。
