## 0. 一条硬约束：中文主名必须全局唯一

`LEXICON` 的结构是 `中文词 → [canonical term, kind]`，**一个中文词只能指向一个 term**。
所以两个语义相近的 term 不能共用同一个中文主名，否则后写的会覆盖先写的。

下面 6 组已经按这条规则拆开了，请你确认这个拆法是否符合你的直觉：

| 组 | 拆法 |
| --- | --- |
| `cap` / `hat` / `baseball cap` | 帽子 / 礼帽 / 棒球帽 |
| `monitor` / `screen` | 显示器 / 屏幕 |
| `bag` / `handbag` | 包 / 手提包 |
| `shoe` / `footwear` | 鞋 / 鞋类 |
| `ice cream` / `soft serve ice cream` | 冰淇淋 / 甜筒 |
| `hair` / `black hair` | 头发 / 黑发 |

**如果你更希望「帽子」这类词一搜就把 cap 和 hat 都带出来**，那需要在检索层支持
「一个中文词映射到多个 term」，而不是在词表里做妥协。**这是设计选择，请你定**——
我默认走「主名唯一 + 同义词分摊」，因为它不改任何数据结构。

## 2. 六个歧义项（只有你能定）

这些都是「照片里到底是什么」，我看标签猜不出来：

| term | 两种可能 | 影响 |
| --- | --- | --- |
| `cream` | 奶油（食物）/ 奶油色（颜色） | 3 张 |
| `orange` | 橙色（颜色）/ 橙子（水果） | 3 张 |
| `sliding` | 滑梯（场景）/ 滑行（动作） | 3 张 |
| `triumphant` | 欢呼（情绪）/ 胜利（场景） | 1 张 |
| `solo performance` | 独奏（乐器）/ 单人表演（舞蹈、演讲） | 1 张 |
| `baby laughing` | 独立成词 / 并入「宝宝」 | 1 张 |

**要不要我逐条去查这 12 张照片的标签文件（`data/labels/<id>.json`）来消歧？**
可以，但那需要再拉一次 `data/labels/`（只读），并且判断结果还是要你看一眼照片确认。
更省事的做法：**你先大概看一眼，这几个词按哪个意思都影响不大**——都是覆盖率 <10% 的长尾。
