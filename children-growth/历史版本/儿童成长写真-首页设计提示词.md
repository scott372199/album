# 备选 A · 儿童成长家庭影像册 · 首页设计提示词

> 版本 v2（家庭内部版）· 2026-11-16
> 定位变更：**从"招生官网"改为"家庭内部影像册"**——面向爷爷奶奶、外公外婆、爸爸妈妈，不对外获客。
> 用途：① 给设计方 / AI 的 Brief；② 与线框稿 `儿童成长写真-首页线框.html` 对照审稿。
> 只想要一段话直接生成，跳到第 10 节。

---

## 1. 定位

| 项 | 内容 |
|---|---|
| 站点性质 | 私人家庭影像册（可加家庭口令，仅家人可看），不是商业官网 |
| 使用者 | 爸爸 / 妈妈（维护者）+ 爷爷 / 奶奶 / 外公 / 外婆（主要观看者，55–75 岁） |
| 核心目的 | 让不在孩子身边的家人，能在 3 分钟内看完"这一年他长成什么样" |
| 成功标准 | 长辈不需要任何人教，自己能翻完、能放大、能存图 |
| 明确不做 | 摄影师介绍、预约、价格、套餐、门店、营业时间、在线咨询 |

**一句话定位**：把孩子的每一年，存成家里人随时能翻开的一页。

---

## 2. 气质与禁止项

**要**：安静 · 留白 · 有时间感 · 可读 · 真实皮肤质感

**不要**：
- 任何商业转化元素：预约按钮、价格、套餐、表单、二维码弹窗
- 摄影师人设、工作室品牌叙事、"我们用 9 年拍过 1200 个孩子"
- 糖果色、高饱和、大圆角卡片、彩色投影、自动轮播、视差滚动
- 图片套白框、拍立得倾斜、贴纸、滤镜
- 文案里的"萌宝""小仙女""爆款""限时"

## 3. 视觉系统

```css
:root{
  --bg:#FAF7F2;      /* 米白 */
  --bg-alt:#F2ECE3;  /* 浅砂 */
  --ink:#1F1D1A;     /* 墨黑，对比度 ≈ 13:1 */
  --ink-60:#5C574F;  /* 次级文字，对比度 ≥ 7:1（长辈可读） */
  --line:#E2DACE;
  --accent:#B4795A;  /* 暖赭，仅编号与时间轴节点，全站 < 5 处 */
  --serif:"Source Han Serif SC","Noto Serif SC","Songti SC",serif;
  --sans:"Source Han Sans SC","PingFang SC","Microsoft YaHei",sans-serif;
  --max:1200px; --gutter:24px; --pad-x:80px; --sec-y:160px;
  --radius:0; --shadow:none;
}
```

**排版（A 版字号整体上调，为长辈让步）**

| 层级 | 桌面 | 移动 | 说明 |
|---|---|---|---|
| H1 | 64 / 1.25 | 34 / 1.3 | 首屏一句，≤ 12 字 |
| H2 | 40 / 1.35 | 26 / 1.45 | 区块标题 |
| H3 | 22 / 1.6 | 19 / 1.6 | 章节名 |
| Body | **17 / 1.9** | **17 / 1.9** | 长辈可读下限，单行 ≤ 30 字 |
| Caption | 13 / 1.8 | 13 / 1.8 | 时间与地点 |
| Label | 11 / 1 | 11 / 1 | 字距 .18em，全大写 |

**硬指标**：正文对比度 ≥ 7:1；点击区域 ≥ 44×44；全站无按钮，仅文字链 + 1px 下划线。

## 5. 首页模块（S1–S10）

### S1 · 首屏
- 全出血单图 A1 + 12% 米白蒙层；文案在右下留白区。
- H1：`把长大，拍慢一点`
- 副标（15px，`--ink-60`）：`我们的孩子 · 2019—2026 · 一共 12 次`
- 唯一次级入口：文字链 `从 2019 开始看 →`（1px 下划线，不是按钮）
- 导航：左 `拾光童年`；右 4 项纯文字 `年份 / 他几岁 / 家里人 / 这本册子`；当前项 1px 下划线，**无实心按钮**。
- 标注：① 首屏只 1 图 1 句 1 入口 ② 文案区对比度 ≥ 4.5:1 ③ 全站无按钮

### S2 · 一句主张
- 居中，最大宽 680，两行：`这些照片没有摆拍。是他忘记镜头的那三秒。`
- 上方 Label：`— 我们的方式 —`；下方可选 A2。

### S3 · 他几岁
- 4 栏，3:4 竖图 + 年龄段 + 一句描述 + 1px 下划线：
  `0–1 岁 / 第一次被看见`、`1–3 岁 / 走路这件事`、`4–6 岁 / 开始有自己的房间`、`7–12 岁 / 背影变长了`
- 每张卡下方加一行 13px 灰字：`2019 · 共 24 张`（长辈关心"有多少张"，不关心"什么风格"）

### S4 · 这一年（三个记忆章节）
- 三行错位（第 2 行右缩进 12% 且图文互换，第 3 行左缩进 6%）。
- 每行：16:10 图 + `YEAR 01 / 2019` + 章节名 + 两行说明 + `看这一年的 24 张 →`
- 章节：`第一次看见海`、`学会骑车的那年夏天`、`搬家后的第一个早晨`

### S5 · 成长时间轴（本册核心）
- 三张同角度 D1–D3 并排 + 1px 时间线 + 6px 圆点，节点标 `1 岁 · 2021`、`3 岁 · 2023`、`6 岁 · 2026`。
- 禁自动轮播；左右 26px 细线箭头，支持键盘 ← →；移动端改纵向堆叠。
- 底部文字链：`看全部 12 次 →`

### S6 · 谁在身边（替代原"关于摄影师"）
- 6 个 1:1 方图横排（H1–H6），下方两行：`奶奶`、`出镜 34 次`。
- 区块标题：`— 谁在身边 —` + 一句：`大部分照片是家里人自己拍的，只有过年会请人拍一次。`
- 标注：这是"家庭感"的来源，不许做成团队介绍。

### S7 · 一句话（长辈的留言）
- 只放 1 条，`--bg-alt` 区块，宋体大引号 76px。
- 引言：`他三岁那年我在住院，是这些照片让我知道他每天都干了什么。`
- 署名：F1 小图 + `外婆 · 2025 年冬`

### S8 · 留给家里（三个功能，无价格）
- 三栏并列，每栏：Label 编号（`01`）+ H3 + 两行说明 + 文字链。
  1. `原图都在` — `点开任意一张可以看原图，长按保存。` → `去下载`
  2. `做成一本册子` — `每年印一本，放在客厅。` → `看看成品`
  3. `只给家里人看` — `这里需要家庭口令才能进，不会被搜到。` → `发给家人`
- 标注：无价格、无表单、无客服入口；"发给家人"只生成链接或口令，不做营销分享。

### S9 · 页脚
- 4 列：`拾光童年`（+ 一句）/ `年份` / `家里人` / `这本册子`（关于 + 隐私说明）。
- 底部 13px：`2019—2026 · 共 12 次 · 286 张照片 · 仅家人可见`

### S10 · 移动端与长辈模式
- < 768：边距 20；H1 34；S3 改 2×2；S4 错位取消改堆叠；S5 纵向；导航收为汉堡。
- **长辈模式**：页面左下角一个极小的"字"图标，点一下整体字号 +2px、行高 +0.1；纯手动，不做自动判断。
- 微信内打开优先：首屏图 ≤ 300KB，点击图片直接进大图，可长按保存。

---

## 6. 文案规则

- 说家里的事，不说品牌的事；主语是"他 / 我们"，不是"我们工作室"。
- 数字只出现三类：年龄、次数、张数（长辈最在意这三样）。
- 全站感叹号 ≤ 1 个；不用"臻选""定格美好""记录每一个瞬间"这类广告语。

---

## 7. 动效

| 场景 | 规范 |
|---|---|
| 区块入场 | 上移 24px + 淡入，600ms，只播一次 |
| 图片 hover | `scale(1.02)` 400ms，仅 `(hover:hover)` |
| 翻页 | 米白蒙层 300ms 淡出，无转场动画 |
| 禁止 | 视差、自动轮播、横向劫持、鼠标跟随 |
| 降级 | `prefers-reduced-motion: reduce` 全部关闭 |

---

## 8. 响应式

| 断点 | 变化 |
|---|---|
| ≥1440 | 内容 1200，边距 80 |
| 1024–1439 | 内容 100%，边距 56，H1 → 52 |
| 768–1023 | 4 栏 → 2 栏，错位取消 |
| <768 | 边距 20，H1 34/1.3，导航汉堡，无底部固定条 |

---

## 9. 验收清单

- [ ] 全站没有"预约 / 价格 / 套餐 / 摄影师"字样
- [ ] 正文 ≥ 17px、对比度 ≥ 7:1、点击区 ≥ 44px
- [ ] 没有实心按钮，全部为文字链 + 下划线
- [ ] 首屏只有 1 图 1 句 1 入口
- [ ] 每张图可点开看原图、可长按保存
- [ ] 全站圆角 0、无投影、无渐变背景
- [ ] 每张图有 `alt`（写画面内容，如"六岁在院子里骑车"）
- [ ] 移动端无横向滚动，微信内首屏 ≤ 1.5s
- [ ] 无自动播放、无弹窗、无第三方统计弹层
