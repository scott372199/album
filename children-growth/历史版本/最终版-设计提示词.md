> 版本 v3 · 2026-11-16

> 合并逻辑：**首页抄 B（一次一张，图最大），二级页抄 A（有年份、找得到）**

---

## 1. 为什么这样合

| 单用 B 的问题 | 单用 A 的问题 | 合并后 |
|---|---|---|
| 长辈不会翻页，找不到"2021 年那张" | 首屏信息太满，图片被裁、被挤在卡片里 | 第一屏满屏一张图，往下滚才有结构 |

一句话：**第一屏让人停下来，第一屏之后让人找得到。**

## 2. 最终结构（已落地在 Demo 里）

```
固定顶栏  我们的孩子 · 2019 2021 2023 2026 · 索引 · 字
─────────────────────────────────────────────
① 首屏      100vh，一张图 contain 居中，底部 01 / 08 + 一句话；← → 翻页
② 一句主张  居中两行，宋体
③ 他几岁    4 栏 3:4 竖图 + 年龄 + 一句 + 「年份 · 共 N 张」
④ 这一年    3 行错位：图上文下，第 2 行右缩进 12% 图文互换，第 3 行左缩进 6%
⑤ 同一个窗口 3 张同角度照片 + 1px 时间线 + 圆点节点
⑥ 谁在身边  6 张 1:1 + 名字 + 出镜次数
⑦ 一句话    外婆的留言，只一条
⑧ 留给家里  原图都在 / 做成一本册子 / 只给家里人看（全是文字链）
页脚        年份 · 家里人 · 这本册子 + 仅家人可见
```

附加两个浮层：

- **索引**（点顶栏"索引"）：8 行纯文字年份，hover 右侧浮出 4:5 小图，点击回到页面 —— 这是 B 的索引页，用弹层实现，不跳页。
- **大图**（点任意照片）：白底 98% 蒙层 + 图 contain + 左下角说明，Esc 关闭。

## 3. 已落地的参数（照这个执行，别改）

```css
--bg:#FFFFFF        页面白
--bg-alt:#FAF8F4    交替区块（极浅暖灰，不是米黄）
--ink:#111111       正文黑
--mute:#767676      说明文字
--rule:#E8E8E8      1px 分隔线
--accent:#B4795A    暖赭，全站只出现在"01 02 03"三个编号上
```

| 项 | 值 |
|---|---|
| 基准字号 | 16px（`html`）→ 长辈模式一键切 18px，全站按 rem 等比放大 |
| 正文 | 1.0625rem / 行高 1.85 / 单行 ≤ 30 字 |
| 标题 | 宋体 300，H2 2.125rem，H3 1.25rem |
| 标签 | 0.6875rem，字距 .18em，全大写 |
| 顶栏 | 固定 44px，白底 94% 不透明 + 8px 模糊，底部 1px 线 |
| 首屏图 | `max-width:76vw` `max-height:100%`，`object-fit:contain`，**绝不裁切** |
| 首屏说明 | 12px，左下，`01 / 08` 用等宽数字 |
| 圆角 / 投影 | 全站 0 |
| 图片统一滤镜 | `sepia(.1) saturate(.94)` —— 让不同来源的照片色温靠近 |

## 4. 交互清单（Demo 里都能试）

| 动作 | 结果 |
|---|---|
| ← / → | 首屏翻页（交叉淡入 280ms） |

## 5. 换成你自己的照片

Demo 用的是占位图（picsum），替换成真实照片只需两步：

1. **按槽位准备图**（与早期截图位编号一致）
   - 首屏 8 张：`gy01–gy08`，横竖混排（3:4 竖 / 3:2 横都可以，容器 contain 不裁）
   - 年龄 4 张 `gy01–gy04`、章节 3 张 `gs01–gs03`（16:10）、时间轴 3 张 `gt01–gt03`（3:4）
   - 家人 6 张 `gp1–gp6`（1:1）、留言头像 `gq1`
2. **替换三处**
   - `<img src="https://picsum.photos/seed/xxx/800/1067" data-cap="...">` → `src="photos/xxx.jpg"`
   - JS 顶部 `SLIDES` 数组里的 `s/w/h` → 换成你的文件名与真实尺寸
   - 上传前统一压到：长边 ≤ 2000px，JPEG 质量 82（首屏那张单独压到 ≤ 300KB）

> 如果替换后色温不统一，把 `filter: sepia(.1) saturate(.94)` 保留，它能把偏冷和偏暖的照片拉到同一个调子上。

## 6. 验收清单

- [ ] 首屏图片完整不裁切，四周留白均匀
- [ ] 首屏只有一张图、一行说明，没有按钮和圆点
- [ ] ← → 翻页、点击图片进大图、Esc 关闭都正常
- [ ] 长辈模式打开后，正文与说明文字都变大，且没有撑破布局
- [ ] 手机上首屏不出现横向滚动，滑动翻页不抢页面滚动
- [ ] 全站没有"预约 / 价格 / 套餐 / 摄影师"字样
- [ ] 每张图都有 `alt`，描述画面内容
- [ ] 断网时显示浅色占位块，不出现破图图标

## 7. 整页生成提示词（可直接复制给 AI）

```
请做一个"家庭内部影像册"的单页网站，中文。使用者是爸爸妈妈（维护）和爷爷奶奶外公外婆（主要观看，55–75 岁）。
绝对不要出现：预约、价格、套餐、摄影师、门店、任何表单。

整体策略：第一屏只放一张图（让人停下来），第一屏之后给出结构（让人找得到）。

视觉：
- 纯白背景 #FFFFFF，交替区块 #FAF8F4；文字 #111111，说明文字 #767676，
  分隔线 1px #E8E8E8，强调色 #B4795A 只用于 01 02 03 三个编号。
- 基准字号 16px；正文 17px / 行高 1.85；标题用宋体 Light（H2 34px，H3 20px）；
  小标签 11px、字距 .18em。全站圆角 0、投影 0。
- 顶栏固定 44px，白底半透明 + 8px 模糊，底部 1px 线；左「我们的孩子」，
  右「2019 2021 2023 2026 索引 字」，全部是文字。

第 1 屏（100vh）：
- 一张照片居中，object-fit:contain，最大宽 76vw、最大高 72vh，绝不裁切，四周大量留白。
- 左下角一行说明：「01 / 08　　一岁 · 2019 · 外婆家的窗口」，12px 灰字。
- 没有任何标题、按钮、圆点；两侧只有两个 1px 细线箭头 ‹ ›。
- 支持键盘 ← →、点击图片左右三分之一、手机左右滑翻页；换图只做 280ms 交叉淡入。
- 首次进入 0.7 秒后浮出一行提示「← → 翻页 · 点击图片看大图」，3.5 秒后淡出，不再出现。

第 2–8 屏（居中最大宽 1280，左右边距 4vw，区块上下留白 110px）：
2 一句主张：「这些照片没有摆拍。是他忘记镜头的那三秒。」宋体两行居中。
3 他几岁：4 栏 3:4 竖图，标 0–1 / 1–3 / 4–6 / 7–12 岁，每栏下方一行说明 + 一行「2019 · 共 24 张」。
4 这一年：3 行错位，每行 16:10 图 + 「YEAR 01 / 2019」+ 章节名 + 两三行说明 + 文字链；
  第 2 行整体右缩进 12% 且图文互换，第 3 行左缩进 6%。
5 同一个窗口：3 张同角度 3:4 照片并排，下方 1px 时间线与圆点节点（3 岁 / 6 岁 / 8 岁）。
6 谁在身边：6 张 1:1 方图，标 爸爸 妈妈 爷爷 奶奶 外公 外婆，各配一行「出镜 34 次」。
7 一句话：#FAF8F4 区块，一条外婆留言，宋体 22px，署名带 40px 圆头像。
8 留给家里：3 栏，只有文字链——原图都在 / 做成一本册子 / 只给家里人看。
页脚：四列（年份 / 家里人 / 这本册子 / 一句话），底部一行「2019—2026 · 共 8 次 · 286 张 · 仅家人可见」。

浮层：
- 索引：点顶栏打开白底全屏浮层，8 行纯文字年份（年份 18px + 一句小字），
  鼠标移到某行右侧浮出 4:5 小图，Esc 关闭。
- 大图：点任意照片打开白底浮层，图 contain 居中，左下角一行说明，Esc 或点空白关闭。

动效：区块滚入时淡入 + 上移 24px，700ms，只播一次；图片 hover 仅 1.02 缩放；
禁止自动轮播、视差、横向劫持；支持 prefers-reduced-motion。
另做一个「字」按钮：点击后根字号 16px → 18px，全站文字等比放大（长辈模式）。

请输出单文件 HTML（内联 CSS + JS），图片位置先用浅色占位块 + 说明文字，方便我替换。
```
