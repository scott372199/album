## 1. 一句话说清 A 与 B 的差别

- **A（备选一）**：有结构、有导航、有说明文字——像一本**编好的书**，长辈能"找"到想看的那一年。
- **B（本方案）**：几乎没有界面，一屏一张图，一句话说明——像一本**只能一页页翻的相册**，情绪更强，但需要人会翻。

## 2. 参照对象实测参数（直接抄，不要自由发挥）

从 `nadavkander.com` 抓到的真实值：

| 项 | 实测值 |
|---|---|
| 背景 / 文字 | `#fff` / `#000`，无任何中间色块 |
| 字体 | Univers Next / Helvetica / Arial，**基准 12px（75%）**，行高 1.6 |
| 顶栏 | 固定（`position:fixed`），白底，底部 1px `#e6e6e6`；站名 700、16.5px、左上角绝对定位 |
| 导航 | 右侧文字列表，12 项，字号与正文同（12px），无图标无按钮 |
| 页面边距 | 左右各 `4vw`（内容容器），列内再 `2vw` |
| 图片 | 居中，垂直水平都居中；按横竖比例给宽度档位（25% / 33% / 100%），**contain，不裁切** |
| 说明文字 | 只有底部一行：`01/40` + caption，左对齐于 4vw |
| 首页形态 | 不是网格，是**一张一张的序列**（Studio Feed），一次只给一张 |
| 动效 | 几乎为零：只有图片切换的淡入 |

**要抄的是它的"克制"，不是它的品牌感。**

## 3. 转译到"家庭影像册"

| 原站元素 | 本方案对应 |
|---|---|
| Studio Feed（一次一张） | 一次一张照片，按时间顺序排（2019 年的第一张 → 现在） |

| Works in Series（作品系列页） | 索引页：纯文字列表，一年一行，hover 才出小图 |
| 单张作品页 | 全屏一张图 + 左下角一行 caption，其余全是白 |

## 4. 四个屏幕

### B1 · 封面（首屏）
- 顶栏：左 `我们的孩子`（700，14px）；右 `2019 2020 2021 2022 2023 2024 2025 2026 索引`（12px，间距 1.4em，当前年加下划线）。
- 主体：**一张图**，居中，高约 72vh，contain 不裁切，宽不超过 76vw；四周全是白。
- 底部一行（12px，左对齐 4vw）：`01 / 286` ＋ 两个空格 ＋ `六岁 · 春天 · 外婆家的院子`。
- 没有任何按钮、圆点、缩略图、标题、Logo 图形。
- 翻页：键盘 ← →；鼠标点图片左/右 1/3；触屏左右滑。

### B2 · 索引（第二屏，滚动即到，不跳页）
- 左侧一列纯文字，8 行：`2019` `2020` … `2026`，每行下面一行小字（如 `第一次看见海 · 24 张`），行距 3.2em。
- 鼠标移到某一行：右侧浮出一张 240×300 的小图（立即淡入 150ms），移开消失。
- 移动端：小图不浮出，改为每行右侧一个 48×60 的缩略图。

### B3 · 单张（点任意图进入）
- 全屏图（contain，最大 86vh / 86vw），白底。
- 左下角：`2019 · 六岁 · 外婆家的院子`；右下角：`024 / 286`。
- 两侧极细箭头（1px 线，20px 高，透明底，hover 才显 30% 黑）；点击图片左右也可翻。
- 顶部保留同一个固定顶栏；`Esc` 返回索引。

### B4 · 页脚（滚到底才出现，只有三行）
```
2019 — 2026
共 12 次 · 286 张
仅家人可见
```

## 5. 样式变量

```css
:root{
  --bg:#fff;
  --ink:#000;
  --ink-40:#666;      /* 唯一允许的灰，用于 caption */
  --rule:#e6e6e6;     /* 1px 分隔线 */
  --sans:"Helvetica Neue",Helvetica,Arial,"PingFang SC","Microsoft YaHei",sans-serif;
  --base:12px;        /* 全站基准字号，不设字号层级 */
  --pad:4vw;
}
```
- **不设字阶**：全站只有 12px 一种字号（站名 14px、索引年份 20px 是唯一例外）。
- 行高统一 1.6；字距 0。
- 圆角 0、投影 0、边框 0（只有 1px 分隔线）。
- 图片全部 `object-fit:contain`，永远不裁切——这是它和 A 最大的视觉差异。

## 6. 动效

| 场景 | 规范 |
|---|---|
| 换图 | 交叉淡入 200ms，无位移、无缩放 |
| 索引 hover | 小图淡入 150ms |
| 翻页 | 无转场、无进度条 |
| 禁止 | 任何 scale、任何视差、任何自动播放 |

---

## 7. 这套方案的代价（要不要选它，看这里）

**优点**
- 图片最大、干扰最小，情绪最集中；长辈看到的第一眼就是孩子。
- 做起来最省事：3 个页面、1 套样式、几乎没有组件。
- 十年后看仍然不过时。

**风险**
- 长辈不知道"可以点""可以按方向键"——**必须加一个首次进入的 3 秒提示**：`← → 翻页 / 点击图片看大图`，消失后不再出现。
- 没有导航结构，找"2021 年那张"比 A 慢；所以 B2 索引页是必需的，不能省。
- 12px 正文对长辈偏小 → 本方案保留 12px 的**视觉气质**，但 caption 与索引说明提到 14px，正文不承载信息，只承载标注。

**一句话建议**：想让人"翻着看"选 B；想让人"找得到"选 A。两者可合并：**B 做首页与单张浏览，A 的索引与导航做二级页**。
